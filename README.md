# Grand Tides

A small, browser-based pirate roguelike adventure built with plain HTML, CSS, and JavaScript.

## Play

Once GitHub Pages is enabled, play at:

https://hacke025.github.io/Grand-Tides/

## Gameplay

- Explore four islands, with later destinations unlocked as you level up.
- Discover treasure, meet helpful strangers, and encounter rival crews.
- Use turn-based actions to fight: quick strike, heavy blow, guard, and (after leveling up) a captain's technique.
- Earn gold, experience, and renown.
- Your voyage is saved locally in your browser.

## Run locally

Open `index.html` in a modern browser. No installation, build tools, server, or external services are required.

## Enable GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save. GitHub will publish the game at the Play URL above.

## Technology

HTML · CSS · Vanilla JavaScript · LocalStorage
